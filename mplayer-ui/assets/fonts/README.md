# UI font

`Figtree-Regular.ttf` is embedded as the primary proportional UI font. Egui's
default fonts remain available for missing glyphs and monospace text.

Source: [Figtree](https://github.com/erikdkennedy/figtree/tree/032dfa7fe219ef3a02890d6d3add84eacc9aebfe),
`fonts/ttf/Figtree-Regular.ttf`, unmodified.
